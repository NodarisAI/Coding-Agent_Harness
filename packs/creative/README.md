# Creative pack

Skills for motion, animation, video and terminal presentation. The pack is general purpose; nothing in it assumes a
particular industry. Start with `creative-studio`, which routes each request to the right skill below.

| Skill | What it is for |
|---|---|
| `creative-studio` | Entry point and routing table for any motion, video or CLI animation request, plus the rules every creative job follows. |
| `product-film` | A 15-25 second film of a product's real screens, built in code with synthetic data and true claims. |
| `video-toolkit` | Choosing between Remotion, Hyperframes, HTML frames and VHS, and tested ffmpeg recipes for trimming, joining, crossfades, captions, music, reframing, GIFs and checks. |
| `terminal-motion` | Splash screens, banners, gradient text, spinners and progress in command-line tools, with the opt-outs and terminal restore they need, and VHS demo recording. |
| `motion-design-direction` | Visual direction before a build: references, typography, palette tokens, the one-sentence intent gate and UI motion principles. |
| `motion-web-pipeline` | End-to-end workflow for an animated website, from direction to a browser-verified page with a numeric colour check. |
| `web-motion-primitives` | Tested, accessible web effect components ready to adapt. |
| `gsap-scroll-motion` | Scroll choreography with GSAP, ScrollTrigger and smooth scrolling. |
| `threejs-webgl-scenes` | 3D and WebGL scenes with Three.js or React Three Fiber, within performance budgets. |
