# Plain copy: text that reads like a careful person wrote it

People who use healthcare software are busy and wary. Text that sounds like marketing or like a chatbot makes them
trust the numbers less. The harness checks visible text after every edit to a UI file and names the phrases that
need rewriting; this skill is how to rewrite them.

Informed by the pattern catalogue in nateherkai/human-speak (MIT), rewritten for product interfaces.

## The standard
- Sentence case, full sentences in messages, the words the user uses for their own work ("claims", "remits",
  "denials", not "records" or "items").
- Say what happened, why if it helps, and what to do next. "The file could not be read. Check that it is an 835
  file and upload it again." Never "Oops! Something went wrong."
- "Click", not "press" or "hit". "Select" for choosing from a list.
- No exclamation marks, emoji or em dashes in interface text. A full stop or a comma does the job.
- Numbers and claims only when they are true and sourced.

## What to cut, and what to write instead
1. **Inflated claims** (seamless, effortless, supercharge, next-level, cutting-edge, world-class, unlock,
   unleash, empower, elevate, harness the power of): name the concrete result. "Posts payments to the right claims"
   beats "Seamlessly supercharge your posting".
2. **Filler** (please note that, it is important to note, a wide range of, at the end of the day, delve,
   leverage, streamline your workflow): delete it; if a sentence dies with it, the sentence had nothing to say.
3. **Tee-ups and reveals** ("Here's the thing:", "The secret?", "What most people miss:"): state the point.
4. **Fake questions** ("Tired of denials?"): make the statement.
5. **Binary reframes** ("It's not a tool, it's a partner"): say what it is.
6. **Vague authority** ("experts agree", "studies show"): name the source or drop the claim.
7. **Stacked adjectives and empty adverbs** (truly, really, incredibly, simply, just): keep the one that carries
   meaning.
8. **Synonym cycling** (claim, record, item, entry for the same thing): one word for one thing, everywhere.
9. **Recap endings** ("In short...", "Ultimately...") and cheerful sign-offs: stop when the information stops.
10. **Mechanical rhythm** (three-item lists everywhere, one-word dramatic sentences, colon reveals): vary it the
    way a person would, or cut it.

## Check before you finish
- Read each changed string aloud. Would a careful account manager at an established software company write it?
- Does every error say what to do next? Does every button say what it does ("Approve 12 claims", not "Submit")?
- Is every number true, and does the screen show where it comes from?
- Rerun the copy check by saving the file again; the harness names anything left.
